Updating RoLocate

A quick guide on how to keep your RoLocate script up to date via GreasyFork automatic updates.

Automatic Updates

By default, automatic updates are enabled when RoLocate is installed from GreasyFork. However, if you edit the script manually or disable automatic updates inside your script manager (like Violentmonkey or ScriptCat), it can disable automatic updates.

RoLocate will tell you in settings if automatic updates are enabled or disabled. If they are disabled, you will have to manually install RoLocate's new updates straight from GreasyFork.

How do you enabled automatic updates? Just go back to GreasyFork and click "Reinstall"

Automatic Update Method

If RoLocate says automatic updates are enabled, then you don't have todo anything! Just chill! :)

Manual Update Method: Reinstalling via GreasyFork

Well easiest method to update RoLocate is to reinstall it from GreasyFork.

  1. Go to the RoLocate GreasyFork page.
  2. Click the button that says "Update To version #" (or "Reinstall") button.
  3. Confirm it
  4. Done!
